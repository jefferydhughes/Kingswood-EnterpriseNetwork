# Kingswood Enterprise & Impact Network

Building sustainable ventures. Creating meaningful impact.
A Kingswood School of Business initiative.

Staff concept preview. Status: Exploratory. Nothing on the site is approved.

## Site

- `index.html` is the whole site (one self-contained page).
- Live at: https://jefferydhughes.github.io/Kingswood-EnterpriseNetwork/

Deployment runs automatically on every push to `main` through `.github/workflows/pages.yml`.
In **Settings > Pages**, **Source** must be set to **GitHub Actions**.
